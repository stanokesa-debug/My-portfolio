# My IT Student Portfolio 🌐

Welcome to my personal portfolio website! 👋  
I am **Stanley Okesa**, a third-year Information Technology student passionate about web development, programming, networking, and exploring new technologies. This portfolio showcases my skills, academic background, projects, and progress in the tech field.

---

## 🚀 About the Project

This personal portfolio website introduces who I am, highlights my technical skills, displays my projects, and provides a way for collaborators, recruiters, and peers to contact me. 

The website is built using **HTML5, CSS3, and JavaScript**, featuring a responsive layout, clean animations, and interactive features.

---

## ✨ Features

- **Home Section:** A brief introduction and welcome message.
- **About Me:** My background, IT interests, and career goals.
- **Skills Section:** Technical skill sets including Web Development, Cisco Networking, and Version Control.
- **Projects Section:** Showcase of academic and personal IT projects.
- **Education Section:** Details on my IT degree coursework and certifications (such as Cisco Networking Academy).
- **Contact Section:** direct contact channels and social links.
- **Responsive Design:** Optimized for seamless viewing across desktop, tablet, and mobile devices.
- **Animations:** Subtle interactive visual effects for an engaging user experience.

---

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Networking & Tools:** Cisco Packet Tracer, Git, GitHub

## 💻 How to Run the Project

1. **Clone this repository:**
   ```bash
   git clone [https://github.com/stanleyokesa/it-student-portfolio.git](https://github.com/stanleyokesa/it-student-portfolio.git)
   ```
2. **Navigate to the project directory:**
   ```bash
   cd it-student-portfolio
   ```
3. **Launch the site:**
   - Double-click `index.html` to open it in your default web browser, or
   - Use the **Live Server** extension in Visual Studio Code for real-time live preview.
